
# Personal-Financial-Tracker

Technologies: Python (Flask), Java (Spring Boot, Maven, JPA), React, JavaScript, CSS, PostgreSQL,Docker,Machine Learning(Future plan)

Overview:

The Personal Finance Tracker is a full-stack application that allows users to log expenses, set budgets, and visualize spending patterns. 
It integrates AI-driven insights and a Personal Financial Assistant chatbot (Future plan) to answer finance-related questions and provide smart recommendations.

Features:

Log daily expenses and track budgets with flexible options.
Visualize spending patterns through interactive graphs.
Export financial reports in CSV or PDF format.
AI-powered insights: predict future spending, identify top expense categories, and provide personalized recommendations.
REST API endpoints for seamless frontend-backend communication.
Robust backend with Flask (Python) and Spring Boot (Java) using PostgreSQL for efficient data management.
Responsive frontend built with React, JavaScript, and CSS.
Will Integrate Personal Financial Assistant chatbot for intelligent, real-time financial guidance.
